# That Day

[English README](README.md)

That Day 是一个 Logseq 插件，用来给“每日日历”添加时间标签。它会读取当前日记页的日期，并把这个日期插入为页面链接或标签，方便你把每天的任务、事件和笔记都关联回对应日期。

## 功能

- 在当前光标位置插入当前日记页日期。
- 支持页面链接格式，例如 `[[2026-05-24]]`。
- 支持标签格式，例如 `#2026-05-24`。
- 可以批量给当前日记页的所有顶层块追加日期标签。
- 已经包含相同日期标签的块会自动跳过，避免重复添加。

## 斜杠命令

| 命令 | 效果 |
| --- | --- |
| `/day` | 插入 `[[YYYY-MM-DD]]` 格式的当前日记页日期。 |
| `/day#` | 插入 `#YYYY-MM-DD` 格式的当前日记页日期。 |
| `/insert all day` | 给当前日记页的顶层块追加 `[[YYYY-MM-DD]]`。 |
| `/insert all day#` | 给当前日记页的顶层块追加 `#YYYY-MM-DD`。 |

## 适用场景

如果你把 Logseq 的日记页当作“每日日历”使用，这个插件可以帮助你快速给内容加上时间标签。这样任务、笔记和事件在之后搜索、查询或复盘时，都能保留清晰的日期线索。
